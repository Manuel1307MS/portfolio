# Portfolio

Personal portfolio website built with Astro and Tailwind.

## Tech Stack

- **Framework:** [Astro](https://astro.build/)
- **Styling:** [Tailwind](https://tailwindcss.com/)

## Getting Started

### Installation

```sh
pnpm install
```

### Development

```sh
pnpm dev
```

### Build

```sh
pnpm build
```

### Preview

```sh
pnpm preview
```
